# 仕様 7.2 通し検証チェックリスト（Easy EQ assistant）

> **目的**: ノイズ測定 → スナップショット → EQ案 → 適用後の再測定（Before/After 比較）を実機で一連実行し、仕様通り動くか確認する。
> **前提**: `cmake --build build` と `ctest --test-dir build` がパスしていること。マイク許可はロック解除状態で取得済み。

---

## 0. 事前準備

| 項目 | 確認内容 | 結果 |
|------|----------|------|
| 0-1 | マイク（ECM8000等）がインターフェースに接続され、ファンタム電源ON | ☐ |
| 0-2 | インターフェースの出力 → 入力（Ref用）をケーブルでループバック配線済み | ☐ |
| 0-3 | スピーカー（またはヘッドホン）が出力に接続済み | ☐ |
| 0-4 | アプリ起動 → デバイス選択で **入力2ch / 出力1ch** を正しく割り当て | ☐ |
| 0-5 | サンプルレート **48 kHz** / バッファ **512 samples** に設定 | ☐ |
| 0-6 | 出力レベル **−20 dBFS**（既定）でフェードイン確認 | ☐ |
| 0-7 | レベルメーター：Ref / Meas / Out の3本が動くこと | ☐ |

## 1. システム補正（ループバック校正）── 仕様 6.1

| 項目 | 操作 | 期待結果 | 結果 |
|------|------|----------|------|
| 1-1 | 「システム補正」ボタンを押す | ピンクノイズが出力され、測定開始 | ☐ |
| 1-2 | 数秒待つ（平均回数 16 程度） | コヒーレンス ≒ 1.0、振幅フラット（±0.5 dB）、位相 ≒ 0° | ☐ |
| 1-3 | 「保存・適用」 | 補正データが保存され、以降の測定で自動適用（ON/OFF で差が出る） | ☐ |
| 1-4 | 補正OFFにして再測定 | インターフェース固有の特性・遅延が見える | ☐ |

## 2. ノイズ測定（伝達関数）── 仕様 3.1, 5.3

| 項目 | 操作 | 期待結果 | 結果 |
|------|------|----------|------|
| 2-1 | スピーカーを鳴らす位置にマイクを置く（ループバックケーブルは外す） | — | ☐ |

## 3. 遅延測定・適用── 仕様 3.3

| 項目 | 操作 | 期待結果 | 結果 |
|------|------|----------|------|
| 3-1 | 「遅延測定」ボタン（Delay/IRタブ） | 相互相関ピークから遅延 ms / サンプル / 距離(m) 表示 | ☐ |
| 3-2 | 「遅延を適用」ボタン | 位相表示が補正後（遅延除去済み）に切替わる | ☐ |

| 3-4 | 内部参照使用時：システム補正の往復遅延が差し引かれ、「空間伝搬遅延」のみ表示 | 数値が物理距離と整合（±10%以内） | ☐ |

## 4. 補正EQ案の作成── 仕様 4 章

| 項目 | 操作 | 期待結果 | 結果 |
|------|------|----------|------|
| 4-1 | 右パネル「ターゲット」で **フラット**（既定）を選択 | ターゲット線が 0 dB 線で表示 | ☐ |
| 4-2 | 補正範囲 **40 Hz〜16 kHz**、コヒーレンス閾値 **0.8** 確認 | — | ☐ |
| 4-3 | 「補正EQ案を作成」ボタン | 最大8帯域の PEQ リストが生成される | ☐ |
| 4-4 | リスト確認：種別・周波数・ゲイン・Q が表示、各帯域 ON/OFF 可能 | 予測カーブ（緑等）が測定カーブに追従する形で重ね描き | ☐ |
| 4-5 | カット優先（−12 dB / +3 dB）、Q 0.5〜10、帯域間隔 ≥1/3 oct に収まっているか | 仕様 4.3 の制約内 | ☐ |
| 4-6 | **CSV書き出し** → ファイル開いて中身確認 | 周波数,ゲイン,Q,種別 の行が正しく出力 | ☐ |
| 4-7 | 手動で1帯域編集（ドラッグ or 数値入力） | 予測カーブがリアルタイム追従 | ☐ |

## 6. 総合判定（仕様 7.2「意図的な変化の復元テスト」）

| 項目 | 判定基準 | 結果 |
|------|----------|------|
| 6-1 | 周波数誤差 | **≤ 1/6 オクターブ** |
| 6-2 | ゲイン誤差 | **≤ ±1 dB** |
| 6-3 | 補正後残差 | **≤ ±1.5 dB**（補正対象帯域・コヒーレンス≥0.8） |
| 6-4 | 操作フロー全体 | **詰まり・クラッシュ・フリーズなし** |
| 6-5 | UI応答性 | **約30 fps 維持、FFT更新で固まらない** |
